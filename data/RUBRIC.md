# Intensity rubric (v0)

Scale is **0–5 integers**. 0 means none of this content. 5 is the ceiling **for a family-film catalog**, not John Wick.

These anchors exist so two people can argue about a movie instead of arguing about the scale.

| | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| **Scary** | None | A shadow, a mean look | Tense adventure, brief peril | Memorable scare kids talk about after | Kids cover their eyes | Nightmare fuel / catalog ceiling |
| **Language** | None | Name-calling, heck / darn / stupid | Mild PG swears (hell, damn, ass once) | Repeated mild, or one strong word | Frequent strong language (PG-13) | Wall-to-wall (R) |
| **Violence** | None | Slapstick, mild bullying | Cartoon scuffles, implied danger | Fights, weapons, on-screen hits, implied death | Sustained action, character deaths, kids in mortal danger | Relentless or graphic on a family scale |
| **Crude** | None | Potty / body humor, light romance | Innuendo, crushes, revealing character design | Sexual jokes, heavy innuendo | Strong sexual content | Explicit (won’t appear in this catalog) |
| **Heavy** | None | Mild family conflict | A real abandonment / identity / loneliness beat | Parent death mentioned or brief, genuine grief | Grief / death / depression is a core thread | Prolonged and devastating — the thing they remember |

## Catalog ceilings (v0)

Use these as the 5s until a later film clearly beats them:

- **Scary 5** — *Toy Story 3* incinerator
- **Language 5** — not in this set (later: an R-rated film)
- **Violence 5** — not in this set (later: *The Lion King* stampede or a PG-13 action film). *The Incredibles* is the current 4.
- **Crude 5** — not in this set
- **Heavy 5** — *Up* Ellie montage

## What each dimension is *not*

- **Scary ≠ violence.** *The Incredibles* is punchy, not creepy. *Finding Nemo*’s anglerfish is creepy, not a brawl.
- **Heavy ≠ scary.** *Up* wrecks adults and some kids via grief, not jump scares.
- **Crude ≠ language.** Swearing vs. innuendo / potty / body stuff.
- Scores describe **what’s in the film**, not whether a particular child will be fine. Thresholds are the parent’s job.

## Review notes

When you disagree with a number, say which anchor you’d move, not just “this feels like a 3.” If the film is right and the anchor is wrong, change the rubric.
